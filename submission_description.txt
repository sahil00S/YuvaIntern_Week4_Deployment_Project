This report documents an end-to-end machine-learning deployment project completed for YuvaIntern Week 4: AI Project Deployment & Capstone. The project is called Wine Classifier Prediction API. It demonstrates how a trained model can be prepared, evaluated, saved, and served through a documented REST API rather than remaining only in a notebook.

The application uses the Wine Recognition dataset distributed with scikit-learn. The dataset contains 178 observations, 13 numeric input features, and three dataset class labels. The training script exports a CSV copy for transparency, uses a stratified 80/20 train/test split, and compares Logistic Regression and Random Forest through five-fold stratified cross-validation. Evaluation includes held-out accuracy, macro precision, macro recall, macro F1, a classification report, and a confusion matrix. Both models obtained a mean cross-validation accuracy of 97.91% with a standard deviation of 2.77%. On the 36-row held-out test set, Logistic Regression reached 97.22% accuracy, 97.78% macro precision, 96.67% macro recall, and 97.10% macro F1. Random Forest scored 100% on this split, but because the cross-validation means tied, the project uses a documented tie-break that selects the simpler Logistic Regression baseline without choosing from the test result. The report explains why one small test split should not be treated as proof of generalization.

The fitted scikit-learn pipeline is serialized using Joblib and loaded by a FastAPI service. The API includes a health endpoint, model-information endpoint, root service information, and a POST prediction endpoint. Pydantic schemas validate all 13 inputs, and the prediction response includes a class identifier, dataset class label, and per-class probability estimates. The project also includes a sample request, saved metrics, generated plots, automated API tests, a requirements file, a Dockerfile, Render configuration, setup instructions, and a PowerPoint presentation. The API smoke-test suite completed with four passing tests. Instructions are provided to run the service locally and to connect the repository to a cloud provider for a public deployment.

This is an educational demonstration. The target labels represent dataset cultivar categories, not wine-quality grades or a safety assessment, and results from this small dataset should not be assumed to generalize to arbitrary real-world samples.
